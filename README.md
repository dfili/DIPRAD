# Analiza RingZer0 i Hack The Box leaderboarda

U Hack the Box mapi nalaze se datoteke za inicijalno testiranje API-ja, skripta za izvlacenje podataka i biljenica za analizu podataka.
U skripti za preuzimanje podataka potrebno je odkomentirati sav kod i pokrenuti je. Dobiveni podaci nalaze se u mapi data.

U RingZer0 mapi nalaze se csv datoteke s preuzetim podacima i Python bilježnica za ekstrakciju i analizu podataka. 
Za ekstrakciju podataka potrebno je slijedno pokretati ćelije u dijelu "Prikupljanje podataka".
